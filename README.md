# 知闯岛 · 小学生知识闯关工作台

在线版入口：`index.html`（手机自动用手机排版，电脑自动用桌面排版）

- `desktop.html` 电脑版入口
- `mobile.html` 手机版入口
- `single.html` 单文件版（一个文件包含全部内容，可离线使用）

## 特点

- 面向小学三至六年级：数学 / 语文 / 英语 / 科学，16 个知识包、400 道题
- 纯静态：无后端、无数据库、不接入任何外部 API 或在线 AI 服务
- 学习记录保存在**访问者自己的浏览器**里（localStorage），不上传、不跨设备同步

## 本地运行

直接双击 `index.html` 即可，或用任意静态服务器托管本目录。
